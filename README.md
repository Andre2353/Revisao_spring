# 🍃 Revisão Spring Framework

> Repositório criado com o objetivo de revisar, estudar e consolidar os principais conceitos e módulos do ecossistema Spring em Java.

O projeto **Revisao_spring** é um laboratório de testes e implementações práticas focado no desenvolvimento de aplicações back-end robustas usando Spring Boot. Aqui estão documentadas as anotações, os padrões de projeto (como MVC) e as configurações de injeção de dependência e persistência de dados.

---

## 📚 Tópicos e Conceitos Revisados

Este repositório cobre (ou cobrirá) as seguintes funcionalidades do Spring:

- [x] **Spring Boot:** Configuração inicial e inicialização rápida (`@SpringBootApplication`).
- [ ] **Injeção de Dependência e Inversão de Controle (IoC):** Uso de `@Autowired`, `@Component`, `@Service`, e `@Repository`.
- [ ] **Spring Web (MVC):** Criação de RESTful APIs com `@RestController`, `@GetMapping`, `@PostMapping`, e mapeamento de DTOs.
- [ ] **Spring Data JPA:** Configuração de persistência de dados, mapeamento de entidades (`@Entity`) e uso de repositórios (CRUD).
- [ ] **Tratamento de Exceções:** Uso de `@ControllerAdvice` e `@ExceptionHandler` para mensagens de erro personalizadas.
- [ ] **Validações:** Uso de Bean Validation (`@Valid`, `@NotNull`, `@NotBlank`).
- [ ] **Spring Security & JWT:** Configuração básica de autenticação e autorização *(se aplicável)*.

---

## 🚀 Tecnologias Utilizadas

O ecossistema principal em estudo utiliza:

* **[Java](https://www.java.com/)** (Versão 17 ou superior recomendada)
* **[Spring Boot](https://spring.io/projects/spring-boot)**
* **[Maven](https://maven.apache.org/)** - Gerenciador de dependências
* **Banco de Dados:** H2 Database (em memória para testes rápidos) ou MySQL/PostgreSQL
